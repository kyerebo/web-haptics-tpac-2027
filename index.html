03

What the web has today

navigator.vibrate() says how, not why.

navigator.vibrate([
  100, 50, 200
]);
  • Raw duration patterns do not communicate intent.A sequence of milliseconds cannot say whether feedback means alignment, a boundary, or confirmation.
  • The API is phone-first and effectively single-engine.It does not reflect today's haptic touchpads, mice, pens, and native OS integrations.
  • The browser cannot select native haptic effects.It receives a waveform instead of the semantic cue needed to choose the right platform effect.

Semantic vocabulary

Six effects cover interaction and outcome.

The browser maps each semantic cue to the native effect that best fits the current device and platform.

Interaction feedback
edge tick align hint
Feedback while an interaction is happening.
Process confirmation
success error
The outcome of a completed action.

Intensity is normalized from 0.0 to 1.0; the platform still applies the user's system setting.

06

Imperative API

When app logic knows when the moment is right.

navigator.playHaptics(effect, intensity)

Use JavaScript for canvas interactions, spatial thresholds, game logic, and other cases that CSS cannot express.

if (elementIsAligned) {
  navigator.playHaptics("align", 0.7);
}
07

Declarative API

Common interaction feedback, without JavaScript in the critical path.

CSS makes routine feedback easy to author and gives the browser room to deliver it with low latency.

Selector state

Nested @haptic

.button:active {
  scale: 0.96;
  @haptic align 0.8;
}
or
Event trigger

haptic property

.button {
  haptic:
    click align 0.8;
}

10

Designed for restraint

Haptics can delight. They can also annoy.

The API minimizes exposed information and gives browsers layers of control over when physical feedback is appropriate.

API Guard the request

  • Sticky activationImperative calls follow a user interaction.
  • Permissions PolicyCross-origin access requires delegation.
  • Silent outcomesNo hardware or playback result is exposed.
  • Semantic vocabularyNo arbitrary waveform programming.

UA Control abuse

  • ThrottlingRate-limit excessive requests.
  • Origin suppressionSilence abusive sites.
  • Global controlsLet users disable haptics.
  • Per-site controlsRespect user choice by origin.
